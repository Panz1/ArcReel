# 三模型视频提示词官方规范对比与方言划分（万相 3.0 × Seedance 2.5 × MiniMax H3）

> 用途：在 `wan3-prompt-spec.md`（万相 3.0 单模型差距调研）基础上，补齐 Seedance 2.5 与
> MiniMax H3 的官方规范调研，做三方对比，回答两个问题：
> ① 哪些写法可以作为**公共标准**进入统一模板（三家官方都认）；
> ② 哪些必须纳入 `PromptDialect` **方言管理**（逐模型不同）。
> 目标形态：一套正文，按模型渲染出各自符合官方标准的完整可用提示词。
> 调研日期：2026-10-25。仅采信官方文档站 / 官方教程 / 官方 API 参考。

## 二、Seedance 2.5 官方规范摘录

**结构公式（导演思维，R2V）**：素材指代（图/视频/音频编号与用途）→ 一句话概述（主体+地点+事件+题材风格+特殊运镜）→ 具体情节描述（**镜头顺序 / 时间轴均可**，逐段画面+运镜+动作+台词+音效，尽量正向描述）→ 反向描述（支持字幕、音频控制两个维度：`不要字幕`、`不要 bgm`）→ 结尾补充贯穿始终的画面细节（机位/运镜、环境、声音、氛围）。

**素材指代**：按上传顺序编号；映射要**文本写明**（不建议只在图片里呈现）：
- 「img1-2 是人物 1，对应音频 1；img3-4 是人物 2」「图片 1 是主角张三，图片 1 使用音频 1 音色」「图 1 的侠客」「参考视频 1 中施法的动作」「image1: 九宫格分镜参考」。
- 官方中文示例以「图 N」「图片 N」为主，英文小写「image1 / img1-2」并存；**未见「Image 1」（大写无空格）形态**（ArcReel 现用形态，语义可认但非官方示例形态）。
- 多主体「逐一列清映射关系，人数多时用清单罗列」；参考素材足够精准时「只做指代、减少画面复述」。
- **多人物错位官方解法**：按人物首次出场顺序上传参考素材，并同步调整提示词中的图片、音频编号，确保一一对应（ArcReel 的 mention 首现顺序编号与此一致 ✓）。

**时间控制（2.5 的关键变化）**：
- **官方明文：Seedance 2.0 不响应时间戳、只响应镜头序号；Seedance 2.5 响应整数秒的时间戳。**
- 三种写法：时间区间（`0-3 秒…3-7 秒` 或 `[1s-4s]…[4s-8s]`）、时间点（`第 5s`）、相对时间（`3 秒后`）。
- 时间轴**保持连续**（避免 `0-3 秒…5-6 秒` 跳段）；以 1 秒为单位理清剧情；时间段内容过少→模型自由发挥，过多→过度剪切；不建议用时间戳控制动作频率。
- 单段 30 秒直出（2.5 能力）。

**台词**：官方多镜头示例为 `台词 (机器人): "I'm right here. I won't let go."`；防字幕技巧为按 `角色台词（情绪）："内容"` 拆分（例：`周女士台词（难以置信）："像……"`）。**未见「X说："…"」作为官方示例句式**（通识可认，但官方形态是「台词 (角色): / 角色台词（情绪）：」）。

**音色 / 口型**：`图片 1 使用音频 1 音色`；视频翻译场景 `要求逐字同步口型`。

**运镜 / 转场**：通识词直接写（景别：大全景/全景/中景/近景/特写；运镜：推/拉/摇/移/跟/环绕/俯冲/后拉/上摇/手持晃动；机位：低角度/俯视/第一人称）；热门词直接写（一镜到底、希区柯克变焦、航拍、FPV、子弹时间、回弹变速）；小众词要「名词+描述性解释」（如移焦）。**转场写清触发点与方式**：`第 5s 快速向左横移转场（向左擦除+自然叠化）`。

**动作 / 表情**：动作优先概括性描述、只在记忆点写细节；表情写描述性语句、减少成语。

**两个官方 badcase 教训**：
- **BGM 诱发**：要禁 BGM 需**穷举同义词**（音乐、背景音乐、BGM、配乐、器乐、旋律、合成器音效、氛围铺底音），且约束写在 prompt **开头与结尾各一遍**——ArcReel 负向清单只有一个「BGM」。
- **字幕诱发**：避免在台词后复述词语并追加语气、表情、动作等描述，此类描述容易诱发字幕生成——与「台词拍带动作」的公共写法存在张力，Seedance 方言需注意把动作描述放在台词**前**而非后。

**其它**：单段 30 秒；参考素材最多 50 个；宽高比 [0.4, 2.5] 自由；强烈推荐官方 Seedance 2.5 skill 调优。

## 三、MiniMax H3 官方规范摘录

**官方无独立结构化 Prompt 指南**。可用官方口径拼出以下事实：

- **示例结构**（video-prompt 页，showcase 级）：时长/比例起手（`15s, 16:9`、`9:16 vertical trailer`）→ 图片角色标注（`Image 1: mood, setting, film grain. Image 2: character. Image 3: bag. Image 4: ending logo.`）→ 核心故事/动作 → 色调与剪辑注记（`Tone premium and cool; edit agile and fashion-forward.`）。另有 `Sound: kitchen ambience plus the creature's soft electronic hums.` 式声音设计行。
- **参考指代**：API 文档口径为英文序数句式（`the character's appearance follows reference images 1 and 2`）与标注式 `Image 1: …`；**`@Image1` 语法未在 API 文档出现**（ArcReel 方言注释已说明取自 H3 前端产品口径——产品口径亦属官方，但两套口径并存）。
- **时间控制**：未文档化秒级时间戳；多拍以叙事序列表达（`…then leaves`），无每段时长指导。
- **运镜**：自然语言（`First-person, eye-level, handheld gameplay camera`、`Medium-close and close shots`、`Subtle handheld shake with recoil kick on fire`）；**方括号 `[command]` 运镜指令只覆盖 Hailuo-2.3 / 02 / T2V-01-Director，不含 H3**。
- **台词 / 音色 / 口型**：无文档化格式；原生音频常开（输入文本/图像/音频/视频，理解 characters, motion, sound, emotion, camera work, style, intent）；音频参考上限 3 段、每段 2-15s、总 ≤15s。
- **Negative**：无 `negative_prompt` 参数、无排除项指导（上轮调研结论：MiniMax 无 negative 通道、官方教程通篇正向叠加）。
- **硬参数**：H3 时长 4-15s（H3 Max 5-15s）；R2V 限 9 图 / 3 视频 / 3 音频、混合 ≤12 文件；prompt ≤7000 字符；768P/2K；T2V 必填 ratio、I2V 恒 adaptive。

## 五、公共标准 vs 方言划分

### 5.1 公共标准（进统一正文与公共指导，三家官方全部兼容）

1. **要素分层**：主体绑定/概述 → 分镜内容（景别+构图+运镜+动作）→ 台词 → 风格 → 约束。万相公式、Seedance 导演思维、H3 示例结构三者同构。
2. **自然语言叙述句 + 大白话运镜词**（推近/拉远/环绕/手持/跟拍、景别五级、机位角度）：三家一致。
3. **台词带引号 + 说话人明确 + 台词嵌在动作拍里**：万相明文、Seedance 示例、H3 原生音频常开均兼容（句式细节各方言）。
4. **参考素材文本绑定**（名字↔编号映射 + 多人逐角色独立绑定 + 首现顺序编号）：万相/Seedance 明文，H3 示例同构。
5. **时间轴连续、每拍 2-5 秒、时长与动作量匹配**：万相明文每段 2-5s；Seedance 明文时间轴连续（内容过少/过多都有官方 badcase）；H3 无时间戳但叙事拍结构同样适用。上轮 P0 的「节拍数按时长动态化」对三家普适。
6. **多人同框写相对站位与朝向**：万相明文（门内偏左/门外偏右）；Seedance 属通识词直写；H3 无反对证据。上轮 P0 的方位词修订对三家普适。
7. **正向描述为主、一镜一种运镜、避免高频动作**：万相明文（避免一秒摇头 3 次）、Seedance 通识、跨供应商共识。

### 5.2 方言管理（`PromptDialect` 需要承载的逐模型差异）

| 方言槽位 | wan3 | seedance-2.5 | seedance-2.0 | minimax-h3 |
|---|---|---|---|---|
| image_ref | `图{n}` | `图片 {n}` | `图片 {n}`（2.5 官方中文口径；现用 `Image {n}` 需校正） | `Image {n}`（API 口径）或保留 `@Image{n}`（前端口径，二选一需拍板） |
| audio_ref | `音频{n}` | `音频 {n}` | 同左 | `audio {n}` / `Audio {n}` |
| 绑定句式 | `图{n}是{X}` + `主体锁定：` | `图片 {n} 是 {X}`（多人清单式） | 同左 | `Image {n}: {X}`（标注式） |
| timecode | `分段N[起-止秒]：` | **`N-M秒：`（2.5 响应整数秒；带秒！）** | `镜头N：`（2.0 不认秒——现状正确，但 2.5 必须分家） | `镜头N：`（无秒级语法） |
| speech | `{X}说："{text}"` | `台词 ({X}): "{text}"` | 同左（待 2.0 页复核） | `{X}说："{text}"`（无官方句式，引号正文即可） |
| 音色绑定 | `音色参考 音频{n}` | `图片 {n} 使用音频 {n} 音色` | 同左 | 无（音频随请求，正文可不写或写自然语言） |
| 口型 | `口型同步` | `逐字同步口型` | 同左 | 无 |
| transition | `硬切转场`/`叠化转场`（段末） | 自然语言（`第Ns …转场（方式）`） | 空串 | 空串 |
| 单镜头标记 | `生成单镜头` | `一镜到底` | 同左 | 空串 |
| negative | `Negative:` 前缀行 | 正文句 `不要字幕。不要 bgm、不要背景音乐、不要配乐…`（穷举+首尾各一遍） | 同左 | 无通道：现 `Avoid:` 行为非官方形态（保留精简版或改正向句式，需拍板） |

## 六、ArcReel 现状差距（本轮新增发现）

1. **seedance 方言按 2.0 口径设计，对 2.5 丢掉了秒级时间戳**——官方明文 2.5 响应整数秒时间戳，`PromptDialect.timecode` 现在对整个 seedance 家族回落 `镜头N：`。需把 SEEDANCE 拆成 `seedance-2.5`（带秒 `N-M秒：`）与 `seedance-2.0`（`镜头N：`）两个方言，marker 按 `capability_names` 先匹配 2.5 再匹配通用 seedance（同 dashscope `WAN3_PATTERN` 的边界匹配教训，防误认）。
2. **SEEDANCE 指代形态**：现用 `Image {n}`（英文大写），2.5 官方中文示例为 `图 N` / `图片 N`（英文小写 `image1` 亦可）。建议对齐 `图片 {n}`。
3. **SEEDANCE 台词句式**：现用 `<{subject}>说："{text}"`，官方示例 `台词 (角色): "…"`。建议方言化对齐（顺带解决尖括号问题——官方句式天然无尖括号）。
4. **BGM 负向强度**：Seedance 官方 badcase 教训是穷举同义词 + 首尾各一遍；ArcReel 只写一个「BGM」。方言化 BGM 约束的写法与位置。
5. **台词后追加描述诱发字幕（Seedance 特有）**：公共「台词拍带动作」写法在 seedance 方言下应把动作放台词前、避免台词后紧跟语气/表情描述（与万相「话音落，麒麟前蹄扬起」的官方写法相反——**这是真正需要方言分支的行为差异**，不只是记号替换）。
6. **H3 的 `@Image{n}` vs `Image {n}`**：`@` 形态未在 API 文档出现（前端产品口径）。建议对齐 API 口径 `Image {n}`，或保留前端口径但在方言注释记录依据。
7. **H3 无 negative 通道**：现 `Avoid:` 行为 ArcReel 自创形态。选项：a) 保留精简（无负面证据，跨供应商实证可认）；b) H3 方言把负向改写为正向句式（官方「正向叠加」口径）。需拍板。
8. 上轮（万相）P0/P1 各项——方位词、节拍动态化、台词拍带动作、负向补项、时间码守护 warning、总体描述、口型同步、尖括号——按 5.1 的检验全部是**公共层**改动，三家同时受益；只有落点记号走方言。

## 七、每模型目标形态（完整可用提示词样例）

同一 unit（张三、李四、酒馆，10 秒，两拍，一句台词）按方言渲染的目标形态：

### 万相 3.0

```
图1是张三，图2是李四，图3是酒馆。主体锁定：张三图1、李四图2。
张三的台词音色参考 音频1，只取音色、语速与情绪，台词以正文为准，声音特征：…。口型同步。
固定空间关系：张三在柜台偏左，李四在门口偏右，两人相对而立，全程保持。

本段10秒：深夜酒馆对峙短剧，节奏由平静转向压抑。
分段1[0-5秒]：中景，张三站在柜台左侧将长剑横放台面，指节叩击剑鞘，李四立在门口右侧按住门框，两人对视，烛焰摇曳，张三说："今晚的酒，我请。"，硬切转场。
分段2[5-10秒]：近景，李四眯起眼睛，嘴角绷紧，缓缓抱起双臂，张三指尖收紧，衣摆随穿堂风轻扬。

Style: …
Negative: BGM、文字字幕、水印、Logo、不要人物无逻辑乱跑、不要空间混乱、不要轴线错乱、不要肢体扭曲、不要人脸变形、不要多余手指、不要换脸、不要缩放漂移
```

### Seedance 2.5

```
图片 1 是张三，图片 2 是李四，图片 3 是酒馆。图片 1 使用音频 1 音色。不要 bgm、不要背景音乐、不要配乐。
一句话概述：两名男子在深夜酒馆对峙的短剧，节奏由平静转向压抑。
0-5 秒：中景，张三站在柜台左侧将长剑横放台面，指节叩击剑鞘，李四立在门口右侧按住门框，两人对视，烛焰摇曳，台词 (张三): "今晚的酒，我请。"
5-10 秒：近景，李四眯起眼睛，嘴角绷紧，缓缓抱起双臂，张三指尖收紧，衣摆随穿堂风轻扬。
不要字幕。不要 bgm、不要背景音乐、不要配乐、不要音乐、不要旋律。
结尾补充：低照度暖光源，全程两人站位保持不变。
```

（动作放台词前、台词后不追加表情语气描述——规避 Seedance 字幕诱发 badcase；BGM 约束首尾各一遍。）

### MiniMax H3
