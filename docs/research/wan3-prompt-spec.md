## 二、官方规范要点（逐项，含与 ArcReel 现状的初判）

### 1. 提示词结构公式

官方公式：**总体描述 + 参考素材引用（图N/视频N/音频N）+ 分镜（起-止秒：主体+场景+运动+美学控制）+ 台词 + 音效/BGM + 风格/情绪 + 负向清单**。
分镜公式：总体描述（一句话交代主题、视角、叙事风格与情绪）+ 镜头序号 + 时间戳 + 分镜内容（动作、台词、表情、场景细节）。

- 「总体描述」是官方公式的第一项，官方示例含总时长与节奏曲线（如「15 秒，节奏由沉稳压抑转为爆发」）。
- **ArcReel 现状**：三段论（声明区 / 正文 / 风格+负向）没有总体描述层，正文直接从「景别：…」开始 → **Gap（G3）**。

### 2. 时间 / 时间段控制

- 时间戳格式不拘：`[起-止]` 与 `（起-止）` 通用，选一种通篇沿用；示例形态有「分镜1（00:00-00:03）」「第2个镜头[4-6秒]」。也可只标序号或只标时间戳。
- 各镜头**首尾相接、不跳段不重叠，每段 2–5 秒**。
- **单镜头**：首行写「生成单镜头 / 一镜到底 / Generate single shot.」。
- **固定镜头**：写「固定镜头，摄影机静止，机位不变」。
- 避免模型控不住的高频动作（如一秒摇头 3 次）。
- 节奏在总体描述里给（「节奏由沉稳压抑转为爆发」）。

- **ArcReel 现状**：`_normalize_timecodes` 已把正文时间码归一为 `分段N[起-止秒]`（在官方许可形态内且通篇统一）✓。但：
  - `reference_video_prompt_authoring` 固定教「切成 **3-5 个**秒级节拍」，对 5–8 秒档 unit 会切出 1–2.7 秒/拍，**低于官方 2 秒下限** → **Gap（G1）**；
  - 渲染层不校验「节拍总和 = duration、段间衔接、单段 ≤5 秒」（上轮待决策⑥）→ **Gap（G2）**；
  - 「生成单镜头 / 一镜到底」未注入（上轮待决策③）；「固定镜头」三联句未系统化（上轮待决策⑤）→ **Gap（G19/G9-固定镜头）**。

### 3. 多主体 / 多人物控制

- 用「图N」分别锁定各主体并切清用途；素材按上传顺序编号，图片/视频/音频分别计数。
- 绑定写法示例：「图1是叶星辰」「小女孩图6、棒棒糖图7」——**全部裸名，无尖括号**。
- 「主体锁定：小女孩图6、棒棒糖图7…」回述强化身份。
- **固定空间关系要写具体方位**：官方短剧示例「叶星辰站在门内偏左，女内门弟子站在门外偏右」＋面对面朝向。
- 不同角色必须用不同参考图，「两人不能共用同一张脸」。
- 一致性负向项：不要人物位置变化、不要服装变化、不要缩放漂移。

- **ArcReel 现状**：图N 顺序绑定 ✓、主体锁定 ✓、分身排除 ✓、每角色独立参考图 ✓。但：
  - 绑定行 / 主体锁定 / 空间声明 / 台词句式全部带内部尖括号记号（`<张三>图1`、`主体锁定：<张三>图1`、`<张三>说："…"`），官方示例全部裸名 → **Gap（G6）**；
  - `_render_spatial_relations` 输出的是抽象声明（「以正文…描述为准」），不产出具体方位；而 `video_body_hard_rules` 又**禁止 LLM 写方位词**（画面左/右、前景/背景）——两头夹击导致多人同框时站位经常没有实际锚点，与官方「门内偏左 / 门外偏右」写法相悖 → **Gap（G4/G5，本轮最重要发现）**。

### 4. 台词 / 口型 / 音色

- 台词格式：**角色 + 说话动词 + 冒号 + 引号内容**（`xx说："xxxx"`）；多人对话逐句书写并标明说话人（「图1说：…；图2回答：…」）。
- 音色克隆：追加「音色参考 音频N」，写一次对该角色全部台词生效。
- **口型对齐：追加「口型同步」或「Lip sync.」**。
- 旁白/独白同样格式（「画外音："xxxx"」）。
- **不要台词需显式写「无台词 / No dialogue.」**，否则模型自行决定。
- 台词协调：官方把台词**嵌在分镜内容里**，配动作与表情（「将军抬眼…沉声道：…话音落，麒麟前蹄扬起」）。

- **ArcReel 现状**：台词句式（方言 `say`）✓、音色声明含「台词以正文为准」限定 ✓、无台词显式声明 ✓（hard_rules 最后第二条）、台词嵌拍 ✓（writing_syntax「台词记号紧跟动作」）。但：
  - **「口型同步」未注入**（上轮待决策②）→ **Gap（G14）**；
  - 台词句式带尖括号（并入 G6）。

### 5. 运镜 / 转场 / 镜头质感

- 运镜用大白话：推近、拉远、环绕、手持跟拍、甩镜、低机位、snap zoom、whip pan、无人机大全景、高速摄影（1000fps 慢动作）等。
- **焦段/景深**：「85mm 长焦，浅景深」「24mm 广角，深焦」。
- 转场：段末写「**硬切转场 / 叠化转场**」，或下段开头写「从上一分段的最后一帧无缝衔接」。

- **ArcReel 现状**：万相多镜头段末自动补「硬切转场」✓（上轮已落地）；unit 间衔接规则（承接/不跳轴/方向/光影/末镜留口）完备 ✓。但：
  - 只有硬切，叠化未开放 → **Gap（G10，低优先）**；
  - 焦段/景深词未教 → **Gap（G9，可选增强）**。

### 6. Negative 负向提示词

- 只写不希望出现的内容，可留空，不重复正向内容，「不必凑数」。
- 官方分类示例：**人物**（不要人脸变形 / 换脸 / 多余手指 / 肢体扭曲 / 穿模）、**文字水印**（不要字幕 / 水印 / 品牌名）、**风格**、**声音**（不要 BGM / **人声旁白**）、**动作**（不要夸张肢体 / 慢动作 / 无逻辑乱跑）、**运镜**（不要大幅运镜 / 频繁切镜 / 持续抖动）、**空间**（不要轴线错乱 / 多人同屏）、**一致性**（不要位置 / 服装变化、缩放漂移）。

- **ArcReel 现状**（`shared/video_avoid.md`）：`BGM、文字字幕、水印、Logo、不要人物无逻辑乱跑、不要空间混乱、不要轴线错乱、不要肢体扭曲、不要人脸变形、不要缩放漂移`。
  - 对照缺口：**多余手指、换脸**（人物类高频崩坏）；**人声旁白**（ArcReel 旁白走 TTS/后期配音，模型自行加旁白会与后期打架——官方把「不要BGM/人声旁白」并列，ArcReel 只禁了 BGM）→ **Gap（G17）**。
  - 「不要位置/服装变化、多人同屏」上轮已评估：与叙事位移/换装/群戏冲突，不全局加，维持 ✓。

### 7. 音效 / BGM

- 官方公式含「音效/BGM」层；BGM 三档：不写由模型自选 / 明确指定 / 写「无 bgm」。

- **ArcReel 现状**：参考生视频路径完全无音效层；BGM 走后期轨并在负向清单禁掉（架构上自洽）。画内音（脚步/物体声/环境声）指导（`shared/ambiance_audio_writing_guide.md`「只描写画内音」）只接入了分镜图生视频路径，参考生路径未接。模型产音（A/B 类）时画内音会实际出声、可提升质感；无声路径写了无效但无害 → **需拍板（G18，涉及音频架构）**。

### 8. 其它硬性要求（复核，均无新差距）

- wan3.0 能力：总时长 ≤15 秒、参考图 10 张、参考音频 5 段共 15 秒、prompt 上限 20000 字符（`dashscope.py` 与官方发布说明一致）。
- 风格三件套（画风+色调+情绪）放开头或结尾：ArcReel `media_style.md` 结尾输出 Style/Visual style ✓。
- 延长任务（输入+输出 ≤30s）、首尾帧与全能参考互斥：与参考生路径不冲突 ✓。
- wan2.7 t2v 旁证：prompt 上限 5000 字符、`negative_prompt` ≤500 字符、`prompt_extend` 默认 true（自动改写）——wan3 无官方 schema，按 2.7 形状类推的现有实现口径不变。

## 三、ArcReel 链路现状（本轮代码走读结论）

两级 LLM + 一层机械渲染：

1. **script_plan**（`text/reference_video_script_plan.md`）：定 unit 边界、时长档位、台词落位、场景引用与叙事正文；有台词下界（口播语速）、打包规则、集节奏硬约束。
2. **prompt_authoring**（`text/reference_video_prompt_authoring.md`）：把正文扩写为「景别→构图→运镜→画面内容」四要素 + 逐拍时间码；台词逐字保留。表演层（micro_expression）、打斗（fight_rule）、段间衔接（unit_shot_continuity_rule）、正文硬约束（video_body_hard_rules，20 条）。
3. **渲染层**（`lib/script/reference_video/prompt_render.py` + `prompt_dialect.py`）：三段论机械拼装——主体绑定/形态声明/主体锁定/声音声明/空间关系声明 → 正文（mention→`<X>`、台词重组、时间码归一、万相段末转场）→ 风格块 + 负向清单。方言（`PromptDialect`）覆盖：图N/音频N、台词句式、Negative: 前缀、时间码格式、主体锁定前缀、转场词。

上一轮（2026-10-24/25）已落地：时间码按方言归一（万相 `分段N[起-止秒]`）、2+ 角色固定空间关系声明、主体锁定回述、万相段末硬切转场、负向清单扩位置/空间/形变项。待决策余项：口型同步、单镜头首行、固定镜头、2–5 秒守护、位置/服装负向（已评估不加）。

## 五、方法说明

- 主指南页为 JS 渲染，经渲染后读取摘录；公式与句式保留官方措辞，长示例只归纳结构。
- wan3.0 无公开 API schema（与 `dashscope.py` 注释口径一致），能力上限（15 秒/10 图/5 音频/20000 字符）以官方发布说明为准（经 `dashscope.py` 间接引用，本轮未重复核对发布页）。
- 本轮最初派出的后台调研 agent 因模型并发上限失败，外部摘录由主会话直接完成；ArcReel 侧结论全部来自代码与模板走读（`prompt_dialect.py`、`prompt_render.py`、`reference_video_prompt_authoring.md`、`reference_video_script_plan.md`、`video_body_hard_rules.md`、`unit_shot_continuity_rule.md`、`micro_expression_rule.md`、`video_avoid.md`、`unit.md`、渲染测试断言）。
